# ⚡ Ежемесячные отчёты (Energy Report)

**Ежемесячные отчёты** — это десктопное приложение для ведения, учёта и анализа показаний потребления электроэнергии, воды и газа. Программа разработана для оптимизации работы энергослужбы и позволяет вести учёт по нескольким точкам (Винзавод 1, Винзавод 2, Винзавод БН).

## 📋 Основные возможности

*   **Учет электроэнергии:** Ведение показаний по трём независимым счётчикам с автоматическим расчётом общего расхода (с учётом коэффициентов).
*   **Учет воды:** Ввод данных по главному вводу и канализации.
*   **Учет газа:** Автоматический пересчёт потреблённого объёма (м³) в Т.У.Т и Гкал на основе заданного коэффициента.
*   **Гибкий расчёт разницы:** Возможность считать потребление «С начала месяца» или «С предыдущей записи» (переключатель в нижней панели).
*   **Локальная и сетевая БД:** Поддержка работы как с локальным файлом `Energy.db`, так и с базой на сетевом диске (настраивается индивидуально для каждого пользователя).
*   **Тёмная тема:** Современный и ненагружающий глаза интерфейс.
*   **Защита паролем:** Доступ к программе защищён кодом (по умолчанию `1111`).
*   **Автообновление:** Проверка наличия новых версий и возможность обновления прямо из программы.

## 🛠 Технологии

*   **Язык:** Python 3.8+
*   **GUI:** Tkinter + ttk (кастомные стили, тёмная тема)
*   **База данных:** SQLite3
*   **Работа с изображениями:** Pillow (PIL)
*   **Календарь:** tkcalendar
*   **Сборка:** PyInstaller
*   **Установщик:** Inno Setup

## 🚀 Установка и запуск

### Для пользователей (Готовый установщик)
1. Скачайте актуальный установщик `EnergyReport_Setup_vX.X.X.exe`.
2. Запустите его и следуйте инструкциям мастера установки.
3. После установки запустите программу с рабочего стола или из меню «Пуск».
4. Введите пароль для входа: **`1111`**.

### Для разработчиков (Запуск из исходников)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Londimain/Energy-Service.git
   cd Energy-Service
   ```
2. Создайте и активируйте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv venv
   source venv/Scripts/activate  # Для Windows
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   python main.py
   ```

## ⚙️ Настройка Базы Данных

При первом запуске программа создаёт локальную базу данных `Energy.db` рядом с исполняемым файлом.

Если вы хотите использовать **сетевую базу** (чтобы несколько пользователей работали с одними данными):
1. Нажмите кнопку **«Настройки»** в верхней панели.
2. Нажмите **«Обзор...»** и выберите путь к файлу `Energy.db` на сетевом диске.
3. Нажмите **«Сохранить»**.
4. Индикатор в левом нижнем углу сменит цвет с зелёного (Локальная) на красный (Сетевая).

*Путь к сетевой базе сохраняется в файле конфигурации в папке `%APPDATA%\EnergyReport\config.json` индивидуально для каждого пользователя Windows.*

## 📦 Сборка и публикация обновлений

Проект включает в себя инструменты для автоматизации сборки и релизов.

### 1. Сборка EXE-файла
Для компиляции основного приложения в один `.exe` файл запустите:
```bash
python build.py
```
Готовый файл `EnergyReport.exe` появится в папке `dist/`.

### 2. Создание установщика
1. Установите [Inno Setup](https://jrsoftware.org/isinfo.php).
2. Откройте файл `energy_installer.iss` в Inno Setup.
3. Нажмите **Compile** (Ctrl+F9).
4. Готовый установщик появится в папке `installer_output/`.

### 3. Публикация обновления
Для рассылки обновления пользователям используйте встроенный публикатор:
1. Запустите `EnergyPublisher.exe` (или `python publisher.py`).
2. В **Шаге 1** укажите новую версию (например, `1.0.1`) и нажмите «Обновить файлы». Скрипт автоматически обновит версию во всех конфигурационных файлах (`version.py`, `.iss`, `version.json`).
3. Соберите EXE и установщик заново.
4. В **Шаге 2** выберите сетевую папку, куда будут складываться обновления.
5. Нажмите «Скопировать установщик и обновить version.json». 

### Сборка самого публикатора
Если вам нужно собрать `publisher.py` в EXE с иконкой, выполните:
```bash
pyinstaller --noconfirm --clean --onefile --windowed --name "EnergyPublisher" --icon="ico/appEnergy.ico" --add-data "ico;ico" publisher.py
```
