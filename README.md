# Энергослужба - Ежемесячные отчёты

Программа для ведения учёта и анализа ежемесячных отчётов энергослужбы.

## 📋 О программе

Программа предназначена для автоматизации учёта показаний приборов учёта энергоресурсов. Поддерживает три основных направления:

- ⚡ **Отчёт по электроэнергии** - учёт показаний трёх счётчиков (Винзавод 1, Винзавод 2, Винзавод БН) с автоматическим расчётом расхода с учётом коэффициентов трансформации (80, 80, 40)
- 💧 **Отчёт по воде** - учёт показаний 7 счётчиков (Главный ввод, Ду20, Ду80, Канализация V, Канализация Тр, Канализация Тпр, Купаж)
- 🔥 **Отчёт по газу** - учёт показаний газового счётчика в Гкал

## ✨ Возможности программы

- **Автоматическая синхронизация данных** - при любых изменениях (добавление, редактирование, удаление) данные мгновенно синхронизируются с базой данных SQLite
- **Автообновление в реальном времени** - реализовано через вычисление MD5-хеша всех данных таблиц. При изменении данных на любом компьютере в сети, все клиенты автоматически обновляют интерфейс через 2 секунды
- **Расчёт разницы показаний** - при выборе месяца автоматически отображается разница с предыдущим месяцем по каждому счётчику
- **Адаптивный интерфейс** - программа автоматически подстраивается под размер экрана (поддержка маленьких экранов)
- **Тёмная тема** - интерфейс выполнен в тёмных цветах для комфортной работы
- **Иконки для навигации** - визуальное оформление кнопок переключения между страницами

## 🛠️ Функционал

### Основные операции
- ✅ Переключение между страницами (Электроэнергия, Вода, Газ)
- ✅ Добавление месячного отчёта с проверкой корректности данных
- ✅ Редактирование существующих отчётов
- ✅ Удаление отчётов с подтверждением
- ✅ Автоматическое заполнение текущего месяца при добавлении

### Особенности
- Форматирование чисел (автоматическое удаление ".0" для целых чисел)
- Выделение чётных/нечётных строк в таблицах для удобства чтения
- Сохранение выделенной строки при обновлении данных
- Отображение подсказки при отсутствии выбранного месяца

## 🗄️ Структура базы данных

### Таблица `electricity`
| Поле | Тип | Описание |
|------|-----|----------|
| month | TEXT PRIMARY KEY | Месяц в формате ГГГГ-ММ |
| meter1_reading | REAL | Винзавод 1 (коэф. 80) |
| meter2_reading | REAL | Винзавод 2 (коэф. 80) |
| meter3_reading | REAL | Винзавод БН (коэф. 40) |

### Таблица `water`
| Поле | Тип | Описание |
|------|-----|----------|
| month | TEXT PRIMARY KEY | Месяц в формате ГГГГ-ММ |
| glavny | REAL | Главный ввод |
| du20 | REAL | Ду20 |
| du80 | REAL | Ду80 |
| kan_v | REAL | Канализация V |
| kan_tr | REAL | Канализация Тр |
| kan_tpr | REAL | Канализация Тпр |
| kupazh | REAL | Купаж |

### Таблица `gas`
| Поле | Тип | Описание |
|------|-----|----------|
| month | TEXT PRIMARY KEY | Месяц в формате ГГГГ-ММ |
| reading | REAL | Показания в Гкал |
